## Core Software

_Core software that enables ecommerce._

### Commerce Platform

- [BigCommerce](https://www.bigcommerce.com) - MACH Alliance member with Catalyst open-source storefront and flexible APIs.
- [commercetools](https://commercetools.com) - MACH founding member and the company that coined "Headless Commerce" with APIs geared towards enterprise clients.
- [Kibo](https://kibocommerce.com) - MACH Alliance member providing unified commerce platform with OMS and ecommerce capabilities.
- [MedusaJS](https://github.com/medusajs) - Open-source JavaScript API-commerce software.
- [Saleor](https://github.com/saleor/saleor) - An open-source API-commerce platform built with Python, Django, and React.
- [SCAYLE](https://scayle.com) - Enterprise commerce platform built for high-growth brands and retailers.
- [Shopware](https://www.shopware.com) - Open-source composable commerce platform for B2B and B2C.

### Content Management System

- [Builder.io](https://www.builder.io) - Visual development platform with MACH-certified composable architecture.
- [ButterCMS](https://buttercms.com) - Easy to use marketing dashboard. Fast content API for modern apps.
- [Contentful](https://www.contentful.com) - The content platform to build digital at scale.
- [Contentstack](https://www.contentstack.com) - MACH founding member offering an agile headless CMS for enterprise content experiences.
- [Cosmic](https://www.cosmicjs.com) - The faster way to manage content.
- [Hygraph](https://hygraph.com) - GraphQL-native federated content platform with MACH certification.
- [Kontent.ai](https://kontent.ai) - Modular content platform for structured content management.
- [LexasCMS](https://www.lexascms.com) - An e-commerce focused headless CMS with built-in support for personalisation, scheduling, and visual previews.
- [Payload](https://payloadcms.com) - Open-source headless CMS and application framework built with TypeScript and React.
- [Prismic](https://prismic.io) - Make your website editable for the whole team.
- [Sanity](https://www.sanity.io) - The ultimate content platform that helps teams dream big and deliver quickly.
- [Storyblok](https://www.storyblok.com) - Visual CMS that helps your team tell your story and manage content for every use-case.
- [Strapi](https://strapi.io) - Design APIs fast, manage content easily.

### Frontend

- [Aries UI](https://aries-ui.com) - Composable commerce frontend accelerator with pre-built components for rapid storefront development.
- [Front-Commerce](https://www.front-commerce.com) - PWA frontend for headless eCommerce.
- [Next Commerce](https://nextjs.org/commerce) - Commerce front-end written in React and Next.js, maintained by Vercel with composable commerce integrations.

### Search

- [Algolia](https://www.algolia.com) - MACH inaugural member and leading search provider, offering cutting-edge UX for web, apps and ecommerce.
- [Bloomreach](https://www.bloomreach.com/en/products/discovery) - AI-powered site search and merchandising solution with Loomi AI.
- [Constructor.io](https://constructor.io) - MACH Alliance member providing enterprise product discovery tailor-made for ecommerce.
- [Coveo](https://www.coveo.com) - MACH Alliance ISV delivering AI-powered search and recommendations.
